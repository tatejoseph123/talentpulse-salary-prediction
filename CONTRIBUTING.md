# Contributing

1. Create a focused branch and keep changes limited to one purpose.
2. Do not alter raw data in place; put derived outputs under `data/processed/`.
3. Do not commit credentials, personal data, checkpoints, or virtual environments.
4. Run affected notebooks or scripts from the repository root.
5. Confirm reported metrics match executed outputs and document methodological changes.
6. Open a pull request describing the change, validation, and effect on results.

Changes to features, target construction, exchange rates, splitting, or evaluation should include before-and-after metrics.
